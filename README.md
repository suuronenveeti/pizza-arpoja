# Pizza-arpoja 🍕

Pizza-arpoja on suoraviivainen, moderni ja minimaalinen verkkosovellus, joka ratkaisee puolestasi ikuisen ongelman: mitä täytteitä valita pizzaan? Sovellus arpoo satunnaisen täyteyhdistelmän sekä sopivan kyytipojan juomalistasta.

Projektissa on käytetty puhdasta ja saumatonta mustavalkoista teemaa, joka mukautuu erillisen painikkeen mukaan valoisaan ja tummaan tilaan.

## Ominaisuudet

* **Täyte-arvonta:** Valitse joko 3 tai 4 täytteen pizza.
* **Juoma-arpoja:** Arpoo satunnaisen ruokajuoman pizzan kaveriksi.
* **Kasvis-tila:** Valintaruutu, jolla voit rajata arvonnasta pois liha- ja merenelävätäytteet.
* **Arvonta-animaatio:** Visuaalinen ja vauhdikas vilkkumisefekti ennen lopullisten tulosten paljastamista.
* **Teemanvaihto:** Saumaton siirtyminen vaalean ja tumman tilan välillä. Valinta tallentuu selaimen muistiin (`localStorage`), mikä estää sivun välkkymisen ladattaessa.

## Teknologiat

* HTML5
* CSS3 (Custom Properties & Modern Typography)
* JavaScript (Pure Vanilla JS, Fisher-Yates shuffle)
